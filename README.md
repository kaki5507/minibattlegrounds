# 🎯 미니 배틀그라운드 (Mini Battlegrounds)

**▶ 플레이: https://minibattlegrounds.onrender.com** (무료 서버라 오래 비어 있었으면 첫 접속 때 1분 정도 기다려야 함)

Escape from Duckov 느낌의 탑다운 웹 배틀로얄 + 타르코프식 탈출 모드입니다. 모바일(터치 조이스틱)과 PC(키보드·마우스)에서 같이 플레이할 수 있습니다.

## 실행 (로컬)
```bash
npm install
npm start          # http://localhost:3000
```
같은 와이파이의 휴대폰에서는 `http://<PC의 IP>:3000` 으로 접속하면 됩니다.

## 무료 배포 (Render 추천)
1. 이 폴더를 GitHub 저장소에 올립니다.
2. https://render.com 가입 → **New → Blueprint** → 저장소 선택 (`render.yaml`이 자동 인식됨)
   - 또는 **New → Web Service** → Build `npm install`, Start `npm start`, Plan **Free**
3. 배포가 끝나면 `https://xxxx.onrender.com` 주소를 친구들에게 공유하면 됩니다. WebSocket도 그대로 동작합니다.

> 무료 플랜은 15분 동안 접속이 없으면 서버가 잠들고, 다음 접속 때 깨어나는 데 30~60초 정도 걸립니다.
> 다른 선택지: Koyeb, Fly.io, Railway(체험 크레딧) 같은 Node 서버 호스팅도 같은 방법(`npm start`, `PORT` 환경변수)으로 동작합니다.
> GitHub Pages나 Netlify 같은 정적 호스팅만으로는 멀티플레이 서버를 돌릴 수 없습니다.

## 게임 기능
| 분류 | 내용 |
|---|---|
| 배틀로얄 | 12000×12000 큰 섬, 마을 17곳. 20명이 서로 멀리 떨어져 시작하고 **처음 60초는 교전 금지**. 자기장 7단계로 한 판 약 10분. 솔로·듀오·스쿼드, 방 비밀번호, 5명 이상이면 자동 시작, 빈자리는 봇 |
| 레이드 (타르코프식) | 16000×16000 **상시 운영 월드**. 대기실·준비 없이 사람이 없어도 계속 돌아가고, 누가 들어와도 같은 맵에서 만남. 입장 전에 현재 인원과 던전별 인원·경비 수를 볼 수 있음. 입장 지점·포탈·탈출구 주변은 몬스터가 생기지도 들어오지도 않는 안전지대. **던전 5개**(폐공장 → 항구 창고 → 지하 벙커 → 군사 기지 → 중앙 연구소, 갈수록 위험·보상 증가), 던전마다 경비 몬스터(죽으면 시간이 지나 다시 생김, 연구소엔 경비대장). 외곽 입장 지점 16곳, 던전끼리 잇는 포탈, **고정 탈출구 5곳**(해안 4 + 연구소 비상구). 개인 제한 시간 25분 |
| 루팅 | 아이템이 바닥에 보이지 않고 **상자(나무 상자·서랍장·더플백·무기 상자·의료 상자·금고)를 수색해야** 내용물이 보임. 죽은 사람은 시체 상자가 되어 소지품을 뒤질 수 있음. 레이드 상자는 시간이 지나면 다시 채워짐 |
| 계정·창고 | 닉네임+비밀번호 계정. 레이드에 장비를 들고 들어가 탈출하면 소지품이 창고에 저장, 죽으면 잃음. 상인 구매/판매 |
| 조작 | 별도 **발사 버튼**(왼쪽/오른쪽, 누른 채 끌면 조준), **조준 버튼**(시야가 조준 방향으로 멀리, 스코프면 1650까지·정확도↑·이동↓), **구르기**(빠르게 옆으로, 도중 무적, 쿨타임 3.5초) |
| 총기 | 탄속이 느려 눈으로 보고 피할 수 있음(저격·지정사수는 빠름). 연사할수록 반동이 쌓여 퍼짐. 부착물 8종, 두 무기 조합 |
| 경험치 | 킬·피해량·생존 시간·수색·우승/탈출로 XP 획득, 레벨 표시 |
| 기타 | 1~3층 건물, 차량(연료), 보급(위치 안내), 방어구 1~3, 수류탄·섬광·연막, 치장 85종 |

## 저장소(DB)
계정·창고는 `DATABASE_URL` 환경변수가 있으면 Postgres(예: Neon 무료)에, 없으면 `data/accounts.json` 에 저장됩니다. Render 무료 서버는 재시작하면 파일이 지워지므로 실제 서비스에는 `DATABASE_URL` 을 꼭 설정하세요.

## 조작
- 모바일: 왼쪽 화면 이동 스틱, 오른쪽 화면 드래그로 조준, 발사 버튼(끌면 조준), 조준·구르기·장전·투척 버튼. 두 번 탭해도 화면이 확대되지 않습니다.
- PC: WASD 이동, 클릭 사격, 우클릭(또는 Z) 조준, Space 구르기, R 재장전, Q 교체, F 수색·상호작용, G/V/T 투척, H/B 치료, Tab 가방, M 지도

## 구조
- `shared.js` — 맵 생성, 충돌, 레이캐스트, 무기·치장 데이터 (서버와 클라이언트가 같이 씀)
- `server.js` — 판정을 서버가 하는 게임 서버(30Hz 시뮬레이션, 15Hz 스냅샷), 방·봇·자기장·차량·보급
- `public/` — 캔버스 클라이언트 (내 캐릭터 이동은 미리 계산해서 바로 반응)

진행 기록(1등·탈출·킬·전리품)은 브라우저 localStorage에 저장됩니다.
