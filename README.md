# 🦆 오리 배틀그라운드 (Duck Battlegrounds)

Escape from Duckov 느낌의 탑다운 웹 배틀로얄 + 타르코프식 탈출 모드입니다. 모바일(터치 조이스틱)과 PC(키보드·마우스)에서 같이 플레이할 수 있습니다.

## 실행 (로컬)
```bash
npm install
npm start          # http://localhost:3000
```
같은 와이파이의 휴대폰에서는 `http://<PC의 IP>:3000` 으로 접속하면 됩니다.

## 무료 배포 (Render 추천)
1. 이 폴더를 GitHub 저장소에 올립니다.
2. https://render.com 가입 → **New → Blueprint** → 저장소 선택 (`render.yaml`이 자동 인식됨)
   - 또는 **New → Web Service** → Build `npm install`, Start `npm start`, Plan **Free**
3. 배포가 끝나면 `https://xxxx.onrender.com` 주소를 친구들에게 공유하면 됩니다. WebSocket도 그대로 동작합니다.

> 무료 플랜은 15분 동안 접속이 없으면 서버가 잠들고, 다음 접속 때 깨어나는 데 30~60초 정도 걸립니다.
> 다른 선택지: Koyeb, Fly.io, Railway(체험 크레딧) 같은 Node 서버 호스팅도 같은 방법(`npm start`, `PORT` 환경변수)으로 동작합니다.
> GitHub Pages나 Netlify 같은 정적 호스팅만으로는 멀티플레이 서버를 돌릴 수 없습니다.

## 게임 기능
| 분류 | 내용 |
|---|---|
| 방 | 방 만들기·목록·빠른 입장, 최대 10명, **5명 이상이면 15초 뒤 자동 시작**, 방장은 바로 시작 가능. 인원이 모자라면 방장이 봇을 채워 시작하거나 90초 뒤 자동으로 시작 |
| 봇 | 배틀로얄은 전체 20명이 되도록 봇 투입. 봇은 루팅·자기장 회피·점사·스트레이프·치료·수류탄 사용. 사람이 나가면 그 캐릭터는 봇이 이어받음 |
| 모드 | **배틀로얄**: 솔로/듀오/스쿼드, 자기장 7페이즈(한 판 약 8~10분). **탈출 모드(타르코프식)**: 10분 레이드, 스캐브 18명과 PMC 봇, 2분 뒤 탈출구 3곳 개방, 7초 서 있으면 탈출, 전리품 가치 저장 |
| 맵 | 8000×8000 섬(에란겔 느낌): 마을 12곳(군사기지·도시·작은 마을), 호수, 도로, 숲, 바위. 1~3층 건물(계단 포탈), 창문(이동은 막고 사격·시야는 통과), 먼 지역을 잇는 순간이동 포탈 3쌍 |
| 시야 | 벽이나 바위에 가려지면 **서버가 적 위치 자체를 보내지 않음**(월핵 불가). 연막탄도 시야를 막음. 다른 층은 보이지 않음. 스코프가 있으면 조준 방향으로 시야가 멀리 늘어남 |
| 총기 | 권총·기관단총·돌격소총·지정사수소총·샷건·저격총·경기관총. 쏠수록 **반동이 누적되어 탄이 퍼지므로 점사해야 함**(조준 부채꼴이 빨갛게 변함). 단발 무기는 한 번 누를 때 한 발 |
| 조합 | 부착물 8종(소음기·보정기·장총열·단총열·확장탄창·퀵탄창·개머리판·조준경), 각각 장단점이 있음. 가방에서 **두 무기를 합쳐 개조총**을 만들 수 있음(피해·사거리↑, 반동·퍼짐·재장전↓) |
| 방어구 | 1·2·3레벨(피해 30/45/60% 감소, 내구도 있음) |
| 투척 | 수류탄(벽 뒤는 안전), 섬광탄(바라보면 더 오래 눈부심), 연막탄 |
| 숙이기 | 1.1초 동안 총알 회피, 쿨타임 5.5초 |
| 치료 | 구급상자(4초, 그동안 움직일 수 없음), 붕대(1.5초). 팀전에서는 기절한 팀원을 4.5초 동안 소생 |
| 차량 | 4인승, 연료 소모, 연료통으로 주유, 들이받으면 피해, 차가 부서지면 폭발 |
| 보급 | 투하 위치를 공지하고 지도·화면 화살표로 안내, 20초 뒤 착지하면 3초 동안 열기 → 고급 무기·3레벨 방어구 |
| 치장 | 7개 칸, 85종: 캐릭터 15종(오리·남자·여자·병아리·고양이·개구리·강아지·토끼·펭귄·판다·곰·로봇·여우·외계인·황금오리, 크기와 뛰는 모습이 다름), 모자 18, 얼굴 11, 장갑 10, 등(가방·날개·제트팩·망토) 9, 총 스킨 10, 옷 색 12. **손이 보이고 총을 손에 쥠**(무기마다 모양이 다르고 소음기·스코프도 보임, 재장전할 때 손이 탄창으로 감). 1등·탈출·누적 킬·판수로 해금, 능력치 효과는 없음 |

## 조작
- 📱 왼쪽 화면을 누른 채 움직이면 이동 스틱, 오른쪽은 조준 스틱(끝까지 밀면 발사). 두 번 탭해도 화면이 확대되지 않습니다.
- 💻 WASD 이동, 마우스 조준·클릭 사격, R 재장전, Q 교체, 1/2 슬롯, Space 숙이기, F 상호작용, G 수류탄, V 섬광, T 연막, H 구급, B 붕대, X 연료, Tab 가방, M 지도

## 구조
- `shared.js` — 맵 생성, 충돌, 레이캐스트, 무기·치장 데이터 (서버와 클라이언트가 같이 씀)
- `server.js` — 판정을 서버가 하는 게임 서버(30Hz 시뮬레이션, 15Hz 스냅샷), 방·봇·자기장·차량·보급
- `public/` — 캔버스 클라이언트 (내 캐릭터 이동은 미리 계산해서 바로 반응)

진행 기록(1등·탈출·킬·전리품)은 브라우저 localStorage에 저장됩니다.
